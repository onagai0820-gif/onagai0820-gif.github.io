マーケットボード

世界の主要な株価指数、ボラティリティ指数、金利、為替、商品、暗号資産、 そしてマーケットのニュースを、1ページにまとめた静的ダッシュボードです。 毎日、自動で更新され続けています。

つくり方

  • サイト本体は HTML / CSS / JavaScript のみ。フレームワークもビルドも使っていません
  • データの取得は Python の標準ライブラリだけで書きました。外部ライブラリはゼロです
  • GitHub Actions が定期的に走ってデータを取り直し、自動でコミットします
  • 検索エンジン向けの情報整備と、アクセス解析の導入まで済ませています

いちばん時間をかけたのは、「載せない」判断でした

データの取得元は、公的機関か正規のベンダーが公開している API だけに絞りました。 非公式の内部エンドポイントは、取れてしまっても使っていません。

そのぶん、無料の範囲では正確な値が取れないものが出てきます。 TOPIX、DAX、FTSE 100、ハンセン指数、KOSPI、日本の個別株、銀。 これらは載せないことにして、その理由もサイトに書きました。 間違った数字を出すくらいなら、無いほうがいいと思ったからです。

調べていて一番ひやっとしたのは、DAX という銘柄コードです。 無料枠でもちゃんと応答が返ってくるのですが、中身はドイツのDAX指数ではなく、 NASDAQ に上場している全然別の銘柄でした。約47ドル。DAX指数は約26,000ポイントです。

コードが一致しているだけでは信用できない。通貨と、取引所と、値の桁を必ず確かめる。 これはこの制作で一番大きな学びでした。

ビジネス 完了 2025

焼きそばパンの手売り

フィリピンでの、はじめての起業体験です。友人と弟との3人で、 焼きそばパンをつくって、現地の人に直接手売りしました。

何をいくらで売るかの計画、材料費の計算、調理、そして販売。 全部の工程を自分たちだけでやりました。誰かに用意してもらった仕組みの上で 動いたわけではない、というのがこの経験の一番の価値だと思っています。

覚えていること

  • 売り切ったときの達成感。あれは他では味わえないものでした
  • 自分たちで稼いだ売上の金額を、実際に目で見たときの感覚
  • 仲間の一人がパン屋に突撃して、焼きそばパンを売りつけてきたこと。今でもあれは暴挙だったと思っています

今フィリピンで飲食の事業を考えているのは、間違いなくこの経験があるからです。

ビジネス 計画中 2026 –

フィリピンでの事業づくり

いま準備を進めているものです。 最初の入り口として飲食や物販を考えていますが、 この分野でやると決めているわけではありません。 うまくいく形が見つかれば、どの方面からでも構わないと思っています。

入り口を、一度変えました

最初は白玉を使ったスイーツを考えていました。日本らしくて、原価も読みやすい。 けれど調べてみると、この場所で求められているのはデザートよりも ご飯ものでした。アイデアを一度置いて、方向を変えることにしました。 その判断の過程はブログに書いています。

進め方

  • いきなり大きく賭けない。小さい規模から始める
  • お客さんの反応を見ながら、次に進むかどうかを決める
  • 価格は、お客さんが気持ちよく払える範囲に置く。搾取はしない

どこまで持っていきたいか

始め方は小さくしますが、目指している規模は小さくありません。 最終的に100億円でバイアウトできるところまで広げられる形を、 最初から選んでおきたいと思っています。

小さく始めることと、大きくならない形を選ぶことは、別の話です。 そこを混同しないようにしたい。

うまくいくかどうかは、まだ分かりません。分かったら、ここに書き足します。
